# MQOM

the benchmark is done for 1 test and results are given in cycles.

to build benchmaking for reference version:

```bash
bash ./build_bench.sh reference
```

and to start the tests:

```bash
bash ./bench.sh reference
```

to build benchmaking for avx2 optimized version:

```bash
bash ./build_bench.sh
```

and to start the tests:

```bash
bash ./bench.sh
```
